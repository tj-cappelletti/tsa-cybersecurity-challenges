# READ-READ-READ

48th Annual PA-TSA State Conference<br>
April 15-18, 2026

## PA-Cybersecurity
This year’s competition will be a Capture the Flag (CTF) event. Students will need to bring at least one laptop (multiple laptops are allowed) capable of connecting to a local wireless network to compete in the event. Please note that no internet will be provided, so students are encouraged to ensure that all tools needed to compete in the event are installed and tested prior to the start of the competition.
Details on how to connect to the network and demonstration of the CTF platform will be provided during the event check-in so all team members must be present.

This year’s categories include, but are not limited to, the following:
- Cryptography (ciphers, encodings, hashes) 
- Forensics (File carving, memory dump analysis, network trace analysis)
- Steganography
- Reverse engineering/malware analysis
- Web Exploitation (SQL injection, cookie manipulation, hidden directories, hidden secrets)

Recommended essential tools:
- Python (latest version)
- Text editor (VS Code, Sublime Text, Notepad++, etc.)
- Web browser with developer tools
- Hex editor (HxD, Hex Friend, xxd, etc.)
- Image/File analysis tools (ExifTool, Binwalk, Steghide, etc.)
- Network analysis tools (Wireshark)
